# AIニュース要約アプリ

> **一行**: AIトレンドを毎日追えない日本語圏のインディーハッカー・エンジニアに、重要トピックを毎朝3件・日本語でメール配信するSaaS。

タグ: `#idea` `#AIニュース` `#メール配信` `#状態:idea`
最終更新: 2026-04-13

---

## 問題

AI関連のニュースは英語が中心で量が多すぎる。毎日チェックする時間がなく、重要な動向を見逃してしまう。日本語で要約されたキュレーションサービスはまだ少ない。

- 英語が苦手または読む時間がない層に届いていない
- 「AIに興味はあるけど追えていない」エンジニア・起業家層が大きい
- 既存の日本語AIニュースサイトはSEO優先でキュレーションの質が低い

---

## ターゲット

- **メインユーザー**: 日本語圏のインディーハッカー・副業エンジニア・スモールビジネスオーナー（30〜45歳）
- **市場規模感**: 小〜中。ニッチだが熱量の高いユーザー層。有料転換率は高いと見る。
- **日本市場での特性**: 英語キュレーションサービス（Morning Brew 等）の日本語版空白地帯。競合は薄い。

---

## ソリューション

毎朝7時に、その日の重要AI関連ニュースを3件・日本語で要約してメール配信する。各ニュースに「インディーハッカーへの示唆」セクションを付け、読むだけでビジネスに活かせる視点を提供する。

---

## Why Now

- LLM が高品質な日本語要約を低コストで生成できるようになった
- AIニュースの量が爆発的に増え、フィルタリングの需要が急増している
- メールニュースレターへの回帰トレンド（SNSの情報過多への反動）

---

## MVP（最小構成）

**MVP のゴール**: 最初の10人が課金するところまで

機能リスト:
- [ ] ニュースソース自動取得（RSS + スクレイピング）
- [ ] LLM による日本語要約生成（Claude API）
- [ ] 毎朝7時のメール配信（Resend）
- [ ] メール登録フォーム（無料トライアル2週間）
- [ ] Stripe による月額課金（無料期間終了後）

**除外すること（MVP では作らない）**:
- ウェブダッシュボード（最初はメールのみ）
- カテゴリ別フィルタ
- 過去アーカイブ検索
- ソーシャルシェア機能

---

## 収益化

- **モデル**: サブスクリプション（月払い）
- **価格帯**: 月額 ¥480〜¥980（年払い割引あり）
- **MRR目標（6ヶ月）**: ¥50,000（約100人 × ¥500）
- **重要指標**: メール開封率・有料転換率・チャーン率

## スタック

```
フロントエンド:  Next.js（Lovable生成）+ Tailwind CSS
バックエンド:    Supabase（DB + Auth + Cron）
LLM:            Claude API（claude-haiku-4-5）
メール配信:      Resend
決済:           Stripe
デプロイ:       Vercel
```

## リスク

- **最大リスク**: LLM の要約品質が読者の期待を下回り解約される
- 大手メディア（日経・NHK等）が同様のサービスを無料で始める
- AI関連ニュースの量が減少するフェーズが来る（ただし短期では考えにくい）
