# プロジェクト管理 — OSSカテゴリ概要

> イシュートラッキング・スプリント・ロードマップ管理。Jira / Linear 代替として根強い需要がある。

タグ: `#category` `#project-management` `#Jira代替` `#Linear代替`
最終更新: 2026-04-13

---

## カテゴリ概要

Jira は機能過多でスモールチームには重すぎる。Linear は洗練されているが月額コストが積み上がる。この空白地帯に OSS 代替への需要がある。セルフホストでデータ管理とコスト削減を両立したいチームに刺さるカテゴリ。

---

## 代表的 OSS ツール

| ツール | 特徴 | セルフホスト難易度 |
|---|---|---|
| [Plane](../tools/Plane.md) | Linear ライクな UI・スプリント・ロードマップ対応 | 中 |
| GitLab | Git + CI/CD + イシュー管理の統合プラットフォーム | 高 |
| OpenProject | ガントチャート・WBS など重厚な PM 機能 | 高 |
| Taiga | アジャイル特化・Scrum / Kanban ボード | 中 |

---

## 代替する商用 SaaS

| 商用SaaS | 月額目安/ユーザー | 主な差異 |
|---|---|---|
| Jira | $7.75〜$15.25 | Plane は大幅にシンプル |
| Linear | $8〜$16 | Plane は機能が近く、セルフホスト可能 |
| Asana | $10.99〜$24.99 | OpenProject がガント機能で代替 |

---

## 典型的なユースケース

- 5〜20人規模のスタートアップが Jira を置き換える
- インディーハッカーがソロプロジェクトのタスク管理に使う
- SaaS 開発チームがスプリント計画・バックログ管理をする

---

## 収益化への示唆（ossalt.jp）

- **コンテンツ価値**: 「Jira 高い・難しい」層への比較記事は検索ニーズ安定。
- **ビジネス機会**: Plane マネージドホスティング + 初期セットアップ代行（月額 ¥3,000〜/チーム）
- **訴求ポイント**: ユーザー数に関係なく月額固定コスト（セルフホスト）の訴求が刺さる

---

## 実装上の注意

- Plane は Docker Compose + `.env` 設定で比較的スムーズに立ち上がる
- SMTP 設定（招待メール）を最初に確認する
- GitLab は要件が重く、個人・スモールチームには GitLab.com 無料枠で十分なことが多い
