# Plane

> **一行要約**: Linear・Jira のオープンソース代替。イシュートラッキング・スプリント・ロードマップ管理ができるセルフホスト可能なプロジェクト管理ツール。

タグ: `#oss` `#プロジェクト管理` `#Linear代替` `#Jira代替`
最終確認: 2026-04-13

---

## 概要

Plane は Next.js + Django で構築されたオープンソースのプロジェクト管理ツール。イシュー管理・サイクル（スプリント）・モジュール（エピック）・ロードマップ・カスタムビューなど、Linear に近い機能セットを提供する。セルフホストで完全無料での利用が可能。

デザインは Linear を強く意識しており、キーボードファーストのUXが特徴。スモールチームやスタートアップが Jira の過剰な複雑さを避けつつ、Linear のコストを削減したい場面に適している。

---

## 代替する商用SaaS

| 商用SaaS | 月額コスト目安 | 主な差異 |
|---|---|---|
| Linear | $8〜$16/ユーザー | Plane はセルフホスト可能、UI は Linear の方が洗練 |
| Jira | $7.75〜$15.25/ユーザー | Plane は大幅にシンプル。エンタープライズ機能は Jira が上 |
| GitHub Issues | 無料〜$4/ユーザー | Plane はロードマップ・スプリント機能が充実 |

---

## 強み

- Linear ライクな洗練されたUI（Jira より遥かに使いやすい）
- セルフホストで全データを自己管理
- イシュー・サイクル・モジュール・ロードマップを一元管理
- API 対応でカスタム統合が可能
- OSS コミュニティが活発でアップデート継続中

---

## 弱み・注意点

- Linear と比較してスピード・洗練度で劣る部分がある
- CI/CD 連携・Slack 通知などの統合は手動設定が必要
- エンタープライズ向け機能（SAML・高度な権限管理）は有料の Plane Cloud 版
- セルフホスト運用コスト（サーバー代・メンテナンス工数）
- 日本語UI は現時点では未対応（英語のみ）

## 実装・導入メモ

- **セルフホスト難易度**: 中
- **必要インフラ**: Docker + Linux VPS（メモリ 2GB 以上推奨）
- **導入ステップ概要**:
  1. 公式の `plane-deploy` リポジトリをクローン
  2. `.env` ファイルを設定（シークレットキー・ドメイン）
  3. `./setup.sh` で自動設定 → `docker compose up -d`
  4. Nginx / Caddy でリバースプロキシ設定
- **注意点**: メール設定（SMTP）がないと招待機能が動かない。最初に必ず設定する。
